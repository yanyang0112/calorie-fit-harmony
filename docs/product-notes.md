# 产品说明

Calorie Fit Harmony 是一个轻量级 HarmonyOS 应用原型，面向希望在减脂期间简单记录每日热量摄入的用户。

## 用户目标

- 快速记录每一餐。
- 直观看到今日摄入是否超过目标。
- 按日期区分饮食记录。
- 复用常吃食物，减少重复输入。
- 查看最近一周的控制情况。
- 保持应用轻量、本地优先。

## 当前范围

- 仅支持本地持久化。
- 暂不支持账号系统。
- 暂不支持云同步。
- 暂不支持食物数据库搜索。
- 暂不支持蛋白质、脂肪、碳水等宏量营养素统计。
- 当前统计能力聚焦七日热量趋势，不覆盖复杂营养分析。

## 后续方向

- 导出每日记录。
- 蛋白质、脂肪、碳水统计。
- 体重趋势记录。
- 更完善的目标热量推荐逻辑。
